# Security Policy

Please do not report suspected security vulnerabilities in a public GitHub issue, discussion, or pull request.

If GitHub Private Vulnerability Reporting is enabled for this repository, use **Security > Advisories > Report a vulnerability** to send the details privately. Include the affected version or commit, reproduction steps, impact, and any suggested mitigation. If private reporting is unavailable, do not put vulnerability details in a public issue. Use a private contact method intentionally published on the maintainer's GitHub profile, if one is available; otherwise withhold the details until a private reporting channel is available.

Tuck is a small, independently maintained project. Security reports are appreciated, but acknowledgement, investigation, fixes, and disclosure coordination are handled on a best-effort basis with no guaranteed response time.
